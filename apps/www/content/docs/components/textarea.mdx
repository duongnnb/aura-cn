## Installation

```bash
npx shadcn@latest add https://raw.githubusercontent.com/duongnnb/aura-cn/master/apps/www/public/r/aura-textarea.json
```

## Usage

```tsx
import { AuraTextarea } from "@/registry/aura-cn/aura-textarea"

<AuraTextarea placeholder="Write something..." />
```

## Props

All native `<textarea>` HTML attributes are supported.
