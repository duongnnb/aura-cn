## Installation

```bash
npx shadcn@latest add https://raw.githubusercontent.com/duongnnb/aura-cn/master/apps/www/public/r/aura-progress.json
```

## Usage

```tsx
import { AuraProgress } from "@/registry/aura-cn/aura-progress"

<AuraProgress value={75} />
<AuraProgress value={45} showLabel />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | `0` | Current progress |
| `max` | `number` | `100` | Maximum value |
| `showLabel` | `boolean` | `false` | Show percentage label |
