## Installation

```bash
npx shadcn@latest add https://raw.githubusercontent.com/duongnnb/aura-cn/master/apps/www/public/r/aura-badge.json
```

## Usage

```tsx
import { AuraBadge } from "@/registry/aura-cn/aura-badge"

<AuraBadge>New</AuraBadge>
<AuraBadge variant="accent">Accent</AuraBadge>
<AuraBadge variant="destructive">Breaking</AuraBadge>
<AuraBadge variant="outline">v0.1</AuraBadge>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "accent" \| "outline" \| "destructive" \| "success"` | `"default"` | Style |
| `size` | `"sm" \| "default"` | `"default"` | Badge size |
