## Usage

```tsx
import { AuraChip } from "@/registry/aura-cn/aura-chip"

<AuraChip>React</AuraChip>
<AuraChip variant="outline">Tailwind</AuraChip>
<AuraChip onRemove={() => console.log('removed')}>Removable</AuraChip>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"aura" \| "default" \| "outline"` | `"aura"` | Visual style |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Chip size |
| `onRemove` | `() => void` | — | Shows remove button when provided |
