## Usage

```tsx
import { AuraPopover } from "@/registry/aura-cn/aura-popover"

<AuraPopover trigger={<button>Click me</button>}>
  <p>Popover content here</p>
</AuraPopover>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `trigger` | `ReactNode` | — | Clickable trigger element |
| `children` | `ReactNode` | — | Popover content |
| `align` | `"left" \| "center" \| "right"` | `"center"` | Horizontal alignment |
| `side` | `"top" \| "bottom"` | `"bottom"` | Vertical position |
