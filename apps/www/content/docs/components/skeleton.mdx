## Installation

```bash
npx shadcn@latest add https://raw.githubusercontent.com/duongnnb/aura-cn/master/apps/www/public/r/aura-skeleton.json
```

## Usage

```tsx
import { AuraSkeleton } from "@/registry/aura-cn/aura-skeleton"

<AuraSkeleton className="h-10 w-full" />
<AuraSkeleton className="h-4 w-3/4" />
<AuraSkeleton className="h-10 w-10 rounded-full" />
```

## Props

All native `<div>` HTML attributes. Use `className` to set dimensions.
