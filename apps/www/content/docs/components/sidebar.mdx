## Usage

```tsx
import { AuraSidebar } from "@/registry/aura-cn/aura-sidebar"

<AuraSidebar items={[
  { label: "Dashboard", active: true },
  { label: "Settings", children: [{ label: "Profile" }, { label: "Account" }] },
]} />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `SidebarItem[]` | — | Navigation items |
| `collapsed` | `boolean` | `false` | Collapsed icon-only mode |
| `className` | `string` | — | Additional CSS classes |
