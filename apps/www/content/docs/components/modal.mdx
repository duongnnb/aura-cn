## Usage

```tsx
import {
  AuraModal,
  AuraModalHeader,
  AuraModalTitle,
  AuraModalDescription,
  AuraModalContent,
  AuraModalFooter,
} from "@/registry/aura-cn/aura-modal"
import { AuraButton } from "@/registry/aura-cn/aura-button"

const [open, setOpen] = useState(false)

<AuraButton onClick={() => setOpen(true)}>Open Modal</AuraButton>

<AuraModal open={open} onOpenChange={setOpen}>
  <AuraModalHeader>
    <AuraModalTitle>Confirm Action</AuraModalTitle>
    <AuraModalDescription>
      This action cannot be undone.
    </AuraModalDescription>
  </AuraModalHeader>
  <AuraModalContent>
    <p>Are you sure you want to proceed?</p>
  </AuraModalContent>
  <AuraModalFooter>
    <AuraButton variant="ghost" onClick={() => setOpen(false)}>
      Cancel
    </AuraButton>
    <AuraButton onClick={() => setOpen(false)}>
      Confirm
    </AuraButton>
  </AuraModalFooter>
</AuraModal>
```

## Props

### AuraModal

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | — | Controls visibility |
| `onOpenChange` | `(open: boolean) => void` | — | Called when backdrop is clicked |

### Sub-components

- `AuraModalHeader` — Top section container
- `AuraModalTitle` — `<h2>` heading
- `AuraModalDescription` — Muted description text
- `AuraModalContent` — Body content area
- `AuraModalFooter` — Bottom actions, right-aligned

## Design Notes

- Rim light gradient from top (elevated pattern)
- Backdrop with `blur-sm` and 60% black overlay
- Animates in with `fade-in` + `zoom-in-95`
- Click outside to dismiss
