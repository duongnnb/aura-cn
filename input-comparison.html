Input vs Button — 6 Styling Approaches

So sánh các cách phân biệt Input (lõm) với Button (nổi)

1
Inset Shadow
Box-shadow hướng vào trong → tạo cảm giác "khoét lõm". Đơn giản nhất, hiệu quả cao.
vs button
2
Bottom Border Accent
Viền dưới sáng + chuyển màu xanh khi focus. Kiểu Material Design, dễ nhận biết.
vs button
3
Darker Background (Sunken)
Nền tối hơn + viền mỏng → trông như "trũng" xuống so với bề mặt. Không rim light.
vs button
4
Floating Label
Label nổi lên trên khi focus/có giá trị. Rõ ràng nhất về mặt UX — luôn biết đó là input.

5
Inverted Rim Light
Gradient sáng từ DƯỚI lên (ngược button). Button sáng trên = nổi, Input sáng dưới = lõm. Tinh tế.
vs button
6
Dashed Border
Viền đứt nét → gợi ý "editable/fillable". Chuyển solid + xanh khi focus. Phân biệt rõ.
vs button
